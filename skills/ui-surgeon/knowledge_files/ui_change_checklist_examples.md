# Canonical UI Change Checklist Examples

Use these as models for concise, review-friendly change checklists after focused front-end edits. Keep them cosmetic, specific, and easy to scan.

## Example 1: Dashboard header and cards

### Project
- Atlas Dashboard

### Scope
- Refine the header, card spacing, and button styling

### Changes Made
- [x] Tightened the header height and improved alignment
- [x] Increased spacing between dashboard cards for better readability
- [x] Updated the primary button color and hover state

### Notes
- Kept the changes cosmetic only and avoided altering behavior

### Follow-up
- Review the updated layout on desktop and tablet breakpoints

## Example 2: Settings page controls

### Project
- Billing Settings

### Scope
- Clean up form spacing and make controls easier to scan

### Changes Made
- [x] Increased spacing between form groups for clearer separation
- [x] Aligned labels and inputs to reduce visual clutter
- [x] Updated link and button styling to match the surrounding interface

### Notes
- No copy, logic, or navigation behavior was changed

### Follow-up
- Confirm the form still reads cleanly at narrow widths
