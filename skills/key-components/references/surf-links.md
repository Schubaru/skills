# designsystems.surf — where to point the user

Use these when they want to compare how mature systems solved something, or when a spec decision deserves a reference. Fetch live only on request; the default knowledge lives in `principles.md`.

## Site map

- Home: https://designsystems.surf/
- Design systems library (90+ systems): https://designsystems.surf/design-systems
- Components directory (2,500+ references, compare anatomy/states across systems): https://designsystems.surf/components — per component e.g. https://designsystems.surf/components/switch
- Foundations directories (typography, color, spacing, tokens, accessibility, Figma libraries): https://designsystems.surf/directories — e.g. https://designsystems.surf/directories/accessibility , https://designsystems.surf/directories/figma
- Articles: https://designsystems.surf/articles
